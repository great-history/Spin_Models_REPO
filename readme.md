# Spin Models

Python code and Jupyter notebooks for Monte Carlo simulations and spin dynamics.

- [NiPS3 Six-Clock Model](NiSP3_SIX_CLOCK/README.md): Honeycomb-lattice spin models with sixfold anisotropy.
- [NiX2 Spin Models](NiX2_SPINS/readme.md): Magnetic order, polarization, topology, and magnon spectra.
- [Two-Spin LLG](two_SPINS_LLG/readme.md): THz-driven spin dynamics and nonlinear response.

See each project's README and notebooks for details.
